# Visual & UX Excellence Standards

## 1. Aesthetic Mastery
- Interfaces must feel modern, premium, and visually engaging at first glance.
- Avoid generic default browser styling.
- Use curated HSL color palettes, deep dark modes, and purposeful accent glows.
- Use modern sans-serif typography (Inter, Outfit, Plus Jakarta Sans, JetBrains Mono).

## 2. Dynamic Interactivity & Feedback
- Incorporate smooth micro-interactions, responsive hover states, and meaningful state transitions.
- Provide clear visual indicators for loading, success, error, and active states.
- Ensure tap targets and interactive controls are accessible and well-spaced.

## 3. Responsive by Default
- Layouts must adapt smoothly across mobile, tablet, and wide desktop viewports.
- Prevent horizontal overflows and test responsive wrapping.
